# C# List Collections Exercises

A collection of practical exercises to master C# List<T> collections.

## 🎯 Learning Objectives
- Adding, removing, and modifying list elements
- Searching and filtering with Find(), FindAll(), Where()
- Sorting with OrderBy(), ThenBy(), Sort()
- Aggregating data with Sum(), Average(), Max()
- Building real-world applications

## 📚 Exercises Included
1. **Student Roster** - Basic CRUD operations
2. **Product Catalog** - Searching and filtering
3. **Playlist Manager** - Sorting and organizing
4. **Sales Analysis** - Data aggregation
5. **Todo List App** - Complete interactive application
6. **Library System** - Advanced challenge
